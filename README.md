# 📚 Books Web Scraping Project

A Python web scraping project that collects book information from [Books to Scrape](https://books.toscrape.com/), a practice website designed for learning web scraping. The project demonstrates how to extract data from multiple web pages, clean and organize it using Pandas, and perform exploratory data analysis.

## 📌 Project Overview

Web scraping is a useful technique for collecting structured information from websites. In this project, I built a Python scraper to automatically collect book information from the Books to Scrape website.

The scraper navigates through the website's pages, extracts book details, and stores the collected information in a structured dataset. The resulting data is cleaned and analyzed to explore the distribution of book prices.

**Website:** [Books to Scrape](https://books.toscrape.com/)

## 🎯 Objectives

- Automate the collection of book information using Python.
- Extract data from multiple pages using pagination.
- Parse HTML content using BeautifulSoup.
- Clean and transform scraped data using Pandas.
- Export the collected information to CSV.
- Perform exploratory data analysis (EDA).
- Visualize the distribution of book prices.

## 🔄 Project Workflow

### 1. HTTP Requests

Used the Requests library to send HTTP GET requests to the website and retrieve its HTML content.

### 2. HTML Parsing

Used BeautifulSoup to parse the HTML and identify the elements containing book information.

### 3. Data Extraction and Pagination

Extracted the following information for each book:

- **Title:** Book title
- **Price:** Listed book price in pounds (£)
- **Rating:** Book rating represented by stars
- **Availability:** Book availability status

Implemented pagination to navigate through the website's pages and collect book information across the catalog.

### 4. Data Cleaning

Used Pandas to organize the extracted information into a DataFrame, remove duplicate records, and convert book prices into numeric values for analysis.

### 5. Data Export

Saved the collected book information into a CSV file for further analysis and reuse.

### 6. Exploratory Data Analysis

Performed basic analysis of book prices, including:

- Number of books collected
- Average book price
- Highest book price
- Lowest book price

Created a histogram to visualize the distribution of book prices.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later
- Jupyter Notebook
  

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Books-Web-Scraping.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Navigate to the project directory

```bash
cd Books-Web-Scraping
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook located at:

`notebooks/web_scraping_project.ipynb`

Run the cells sequentially to execute the scraping, data cleaning, and analysis workflow.

## 📁 Dataset

The scraped dataset is saved as:

`databooks.csv`

Each row represents a book, with columns containing its title, price, rating, and availability.

The dataset is generated by the scraper rather than manually collected.

## ⚠️ Limitations

- The project uses a practice website intended for educational web scraping.
- The scraper collects the information made available in the website's HTML.
- The analysis focuses on book prices and does not evaluate book quality or customer preferences.
- The collected prices represent the website's listed prices at the time of scraping.
